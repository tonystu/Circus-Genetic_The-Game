# Circus Genetic: five small upload batches

Use these five ZIPs instead of the previous large ZIP or single-file HTML.
Each ZIP is a separate batch. You need all five for the complete game.

1. Download and extract Batch 1 into its own folder.
2. In your GitHub repository, choose Add file > Upload files.
3. Drag the CONTENTS of the extracted folder into the upload area. Do not drag the ZIP or the outer batch folder.
4. Commit the changes before uploading the next batch.
5. Extract Batch 2 into a separate folder. Upload its assets folder into the repository ROOT, and commit. Repeat for Batches 3, 4 and 5. GitHub will merge the assets into the existing assets folder.
6. The final repository root must contain index.html, styles.css, scripts/, and assets/. Do not put assets inside another assets folder.
7. If replacing an older export, accept the new small index.html and other replacement files.
8. After all five batches are committed, go to Settings > Pages. Choose Deploy from a branch, main, /(root), and Save.

The game will be incomplete until every batch has been uploaded. If GitHub still rejects one extracted batch, save a screenshot of the exact message so the specific limit can be identified.

This is the complete browser game. The artwork and music have not been reduced. No Windows installer belongs in this upload. See GAME-README.md for the game guide.

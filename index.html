LINER NOTES

A FEW THINGS
BEFORE THE GIG.

DO I NEED TO INSTALL ANYTHING?

No. The web edition runs in your browser. For the full controls, use a desktop or laptop with a keyboard. Click the amp's power button to start and enable audio.

CAN I SKIP TO A CHAPTER?

Yes. Use Chapter Select on the game's title screen, flip through the CD bin, and choose your player. A perfect full-night run starts with Start New Band.

DOES IT SAVE MY RUN?

This edition has no mid-level Save/Load. Closing or reloading the game does not preserve a run in progress. Chapter Select lets you revisit sections.

WHAT'S THE VIBE?

Strong language, cartoon violence, suggestive humor, alcohol, and smoking/cannabis references. In other words: probably not the game for the kindergarten fundraiser.

IS THERE SOMETHING HIDDEN?

Some records have a secret track. Some boxes have a clue.
